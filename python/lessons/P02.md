## 已授要点

- list 的 == 按内容比较，is 比较对象身份；判断 None 通常用 is None。
- 不同变量名可能指向同一个对象；不能据变量名判断是否共享对象。
- or 根据真假值选择操作数，空列表、零也会触发默认值；仅缺省时回退应明确判断 None。
- 链式比较可写 0 <= temperature <= 2；范围校验需检查等号边界。
- // 向下取整，包括负数；for 不引入独立块作用域。
- enumerate 索引对应原始遍历位置，continue 不重新编号；break 退出当前循环。
- and 左假短路，or 左真短路，返回操作数而非保证 bool。
- 未捕获异常中止当前执行，连续放多个错误调用不能验证所有案例。

## 课堂例子与复测

```python
a = [{"score": 1}]
b = [{"score": 1}]
c = a
b[0]["score"] = 2
print(a == b, a is c, a[0]["score"])  # False True 1
```

两次分别创建的列表与字典不共享；不同名字本身不能证明对象不同。

```python
supplied_docs = []
docs_a = supplied_docs or ["默认文档"]  # ["默认文档"]
docs_b = ["默认文档"] if supplied_docs is None else supplied_docs  # []
```

接口若规定 None 为未提供、[] 为明确不使用文档，写法 B 正确。Python 空 list/dict 为假，JS 空 Array/Object 为真。

```python
docs = ["", "文档A", None, "文档B", "STOP", "文档C"]
processed = 0
for index, doc in enumerate(docs):
    if doc is None or doc == "":
        continue
    if doc == "STOP":
        break
    print(index, doc)
    processed += 1
print("processed:", processed)
# 1 文档A
# 3 文档B
# processed: 2
```

`text is not None and len(text) > 0` 在 text 为 None 时短路，不执行 len(None)。
