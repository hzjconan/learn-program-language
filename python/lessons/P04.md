## 1. 新容器与共享元素

```python
docs = [{"id": "a", "score": 0.6}, {"id": "b", "score": 0.9}]
selected = [doc for doc in docs if doc["score"] >= 0.8]
selected.append({"id": "c", "score": 1.0})
selected[0]["score"] = 0
print(len(docs))                       # 2
print(docs[1]["score"])                # 0
print(selected is docs)                # False
print(selected[0] is docs[1])           # True
```

推导式创建新列表，里面仍存原字典的引用。append 修改新列表，字段赋值修改共享字典。selected 筛选后长度为 1，append 后长度为 2。

## 2. 替换引用与修改对象

若从初始数据重新开始，改为 `selected[0] = {"id": "b", "score": 0}`，替换的是新列表这个位置的引用，原字典保持 score=0.9，两个字典不再是同一对象。

名字不同不能证明对象不同；赋值保存引用，不自动保存内容快照。

## 3. 浅拷贝与深拷贝

列表的 copy()、[:]、list(...) 创建新的外层列表，元素对象仍共享；类似 JS 的 [...docs]。

```python
docs = [{"id": "a", "score": 0.9, "tags": ["python"]}]
copied = [doc.copy() for doc in docs]
copied[0]["score"] = 0
copied[0]["tags"].append("ai")
print(docs[0]["score"])                # 0.9
print(docs[0]["tags"])                 # ['python', 'ai']
print(copied[0] is docs[0])             # False
print(copied[0]["tags"] is docs[0]["tags"])  # True
```

字典 copy 也只复制一层。给新字典 score 赋值不改变旧字典；append 作用于共享 tags 列表。

```python
from copy import deepcopy
docs = [{"id": "a", "score": 0.9, "tags": ["python"]}]
copied = deepcopy(docs)
copied[0]["tags"].append("ai")
print(docs[0]["tags"])                 # ['python']
print(copied[0]["tags"])               # ['python', 'ai']
print(copied[0]["tags"] is docs[0]["tags"])  # False
```

对于本题普通嵌套列表/字典数据，deepcopy 递归复制容器，隔离原对象与副本。不要直接将这种做法推广到大型模型、连接等任意对象。

## 4. 可变默认参数

```python
def add_message(text, history=[]):
    history.append(text)
    return history

first = add_message("你好")
second = add_message("介绍一下 Python")
print(first)   # ['你好', '介绍一下 Python']
print(second)  # ['你好', '介绍一下 Python']
print(first is second)  # True
```

默认值在执行 def 时求值，不是每次调用重新创建。两次返回同一个列表，第二次调用改变它之后再打印 first，看到的也是更新后的内容。

```python
def add_message(text, history=None):
    if history is None:
        history = []
    history.append(text)
    return history
```

None 哨兵让未传参数的调用各自创建列表；显式传 existing 列表时仍会修改 existing，result is existing 为 True。参数传递不自动拷贝对象。

## 5. 主练习：独立消息历史

实现 append_message(history, role, content)：None 按空历史处理，返回追加新消息后的独立列表；修改已有消息的字段或嵌套标签不影响原历史。假定 role/content 为字符串，历史由普通列表、字典和基本值组成。

验收：原长度 1、新长度 2；修改副本 content 原值不变；副本 metadata.tags append 后原标签不变；两次 None 调用相互独立；空列表输入不变。验证代码放 main，入口判断保护导入。

局部执行 `history = deepcopy(history)` 是重新绑定名字，不改变调用方变量指向；之后 append 修改副本。去掉拷贝会修改调用方列表，首先导致 `assert len(original) == 1` 失败。
