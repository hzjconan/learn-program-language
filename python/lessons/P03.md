## 已授知识与例子

### 索引与切片

`items[start:stop:step]` 左闭右开；[-1] 取倒数第一个元素，不是取一个元素。切片上界超出范围会限制到序列范围，直接索引越界则报错。

上述四题结果："E"、["B", "C", "D"]、["A", "C", "E"]、["D", "E"]。`items[::-1]` 反向切片。

### 字典查询与缺省值

dict.get(key, default) 只在键不存在时返回 default；键存在但值为 None、0 或空字符串，仍返回原值。`key in meta` 检查键。

上述四题结果：0、None、"未知"、True。不要和 `meta.get(key) or default` 的真假值回退混淆。

### 去重、顺序与排序

- set 去重，不保证业务需要的遍历顺序；sorted(set(ids)) 得到排序后的唯一值。
- dict 保留插入顺序，重复赋值不改变已有键的位置；list(dict.fromkeys(ids)) 保留首次出现顺序，本题为 ["b", "a", "c"]。
- list.sort 原地修改、返回 None；sorted 返回新列表，不修改原列表顺序。
- `sorted(docs, key=lambda doc: doc["score"], reverse=True)` 按分数降序；lambda 是匿名函数表达式，类似 JS 箭头函数。
- 排序稳定，同分记录保留输入的相对顺序。排序后 [:2] 取前两条。

### 元组

point = (3, 4) 是 tuple；(3) 是加括号的 int；单元素元组写 (3,)。tuple 不允许替换元素，point[0] = 9 抛 TypeError。内部可变对象问题留到 P04。

### 推导式

```python
ids = [doc["id"] for doc in docs if doc["score"] >= 0.8]
scores = {doc["id"]: doc["score"] for doc in docs}
```

列表推导式按“遍历→过滤→计算结果”理解；字典推导式重复键后值覆盖前值，不自动聚合。可对照 JS filter/map。

### zip 配对与严格长度

```python
ids = ["a", "b", "c"]
scores = [0.9, 0.8]
print(list(zip(ids, scores)))  # [("a", 0.9), ("b", 0.8)]
```

zip 产生配对元组，默认到最短输入耗尽时停止，不补默认值。`list(zip(ids, scores, strict=True))` 在消费到长度不一致时抛 ValueError；仅创建 zip 对象并不立即检查完长度。

```python
ids = ["a", "a"]
scores = [0.9, 0.8]
print(list(zip(ids, scores, strict=True)))  # [("a", 0.9), ("a", 0.8)]
print(dict(zip(ids, scores, strict=True)))  # {"a": 0.8}
```

strict=True 不检查 ID 唯一性，字典覆盖规则独立存在。文档和 embedding 配对时要根据业务分别检查长度和唯一性。

## 主练习：整理检索结果

实现 [prepare_results.py](../prepare_results.py) 中 prepare_results(docs, min_score, top_k)：

1. 保留 score >= min_score 的文档。
2. 按分数降序。
3. 按 id 去重，保留排序后的首次记录；同分保留输入中较早的记录。
4. 取前 top_k 条；零返回空列表，超过长度返回全部。
5. 不改变原 docs 顺序；本题不要求复制内部字典。

假设字段和类型正确、top_k 为非负整数。输入依次为 a/0.6、b/0.9、a/0.95、c/0.8、d/0.8、b/0.7。

| min_score | top_k | 预期 ID |
|---|---|---|
| 0.8 | 3 | a、b、c |
| 0.8 | 10 | a、b、c、d |
| 0.8 | 0 | 空 |
| 1.0 | 3 | 空 |

教师补测空输入、同 ID 同分保留首条、最高分保留和原输入不变，均通过。用户正确指出直接 docs.sort 会改变调用方输入顺序。
