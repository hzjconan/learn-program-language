def request(model, temperature=0.7):

## 1. 参数绑定与默认值

调用时，位置参数按顺序绑定，关键字参数按名称绑定。对于 `request(model, temperature=0.7)`，`request("demo", 0)` 和 `request(temperature=0, model="demo")` 都返回 `("demo", 0)`。Python 的关键字参数由语言直接支持，JS/TS 里常用 options 对象表达类似意图。

| 调用 | 结果与原因 |
|---|---|
| `request("demo")` | `("demo", 0.7)`，省略 `temperature` 才用默认值 |
| `request(temperature=0, model="demo")` | `("demo", 0)`，显式传入的 `0` 已完成绑定 |
| `request("demo", model="other")` | `TypeError`，`model` 同时收到位置值和关键字值 |
| `request(temperature=0)` | `TypeError`，缺少必填 `model` |

传入 `0`、`False` 或 `None` 都算提供了值。函数默认值不会根据真假值回退。可变默认值何时创建见 [P04](P04.md)。

## 2. 用 `*` 和 `/` 限制传参方式

```python
def generate(prompt, *, temperature=0.7, max_tokens=100):
    return prompt, temperature, max_tokens

generate("你好", temperature=0)         # ("你好", 0, 100)
generate(prompt="你好", max_tokens=200)  # ("你好", 0.7, 200)
generate("你好", 0, 200)                # TypeError
```

独立 `*` 后只能按名字传。`max_tokens=200` 让读调用的人知道数值代表什么，适合模型接口中的可选配置。`/` 前只能按位置传。两者之间的普通参数两种方式均可。

```python
def generate(prompt, /, model="demo", *, max_tokens=100):
    return prompt, model, max_tokens

generate("你好", "other", max_tokens=200)  # ("你好", "other", 200)
generate("你好", model="other")           # ("你好", "other", 100)
generate(prompt="你好", model="other")    # TypeError，prompt 只能按位置传
```

## 3. 定义时收集，调用时展开

定义中，`*args` 把剩余位置参数收成元组，`**kwargs` 把剩余关键字参数收成字典。`args`、`kwargs` 是惯用名。带名字的 `*args` 会收集位置参数，其后的具名参数仍须按名字传。

```python
def inspect_call(model, *args, temperature=0.7, **kwargs):
    print(model)
    print(args)
    print(temperature)
    print(kwargs)

inspect_call("demo", "消息A", "消息B", temperature=0, stream=True, max_tokens=200)
```

```text
demo
('消息A', '消息B')
0
{'stream': True, 'max_tokens': 200}
```

`temperature` 由显式参数接收，`kwargs` 只保留其余关键字。调用时方向反过来，`*` 将可迭代对象逐项展开为位置参数，`**` 将映射展开为关键字参数。

```python
messages = ["消息A", "消息B"]
options = {"temperature": 0, "stream": True}
inspect_call("demo", *messages, **options)
# 等价于 inspect_call("demo", "消息A", "消息B", temperature=0, stream=True)
```

## 4. 配置覆盖与关键字冲突

```python
defaults = {"temperature": 0.7, "max_tokens": 100}
overrides = {"temperature": 0}

inspect_call("demo", **{**defaults, **overrides})  # 成功
inspect_call("demo", **defaults, **overrides)      # TypeError
```

第一行先创建一个字典。后面的 `temperature` 覆盖前面的值，函数收到 `temperature=0`，`kwargs` 是 `{'max_tokens': 100}`。第二行在调用阶段把同名关键字传了两次，函数体一行也不会执行。显式关键字和解包字典重名同理，例如 `inspect_call("demo", **defaults, temperature=0)`。

## 5. 主练习：封装模型调用的默认配置

底层 `generate(prompt, /, *context, model="demo", temperature=0.7, max_tokens=100)` 返回实际收到的字段。封装 `generate_with_defaults(prompt, /, *context, **overrides)`，将封装层默认 `max_tokens` 改为 `200`，把位置上下文和合并后的关键字配置转发给底层。

| 调用 | 验证点 |
|---|---|
| `generate_with_defaults("你好")` | 上下文是 `()`，温度为 `0.7`，最大 token 数为 `200` |
| `generate_with_defaults("总结", "材料A", "材料B", temperature=0, max_tokens=50)` | 上下文顺序保留，温度为 `0`，最大 token 数为 `50` |
| `generate_with_defaults("你好", model="other")` | 模型覆盖生效 |
| `generate_with_defaults("你好", max_token=50)` | 未知关键字传给底层并触发 `TypeError` |

初版逐项用 `.get()` 读取已知字段，前几个行为正常，但会忽略拼错的 `max_token`，使调用看起来成功。修订版把完整配置交给底层，底层签名会拒绝未知关键字。

如果只是合并默认值，可以把默认配置集中到一个字典。写成 `{**defaults, **overrides}` 即可表达覆盖顺序，逐项 `.get()` 可以省掉。修订版已通过验证，具体过程见 [笔记](../notes/P05.md)。
