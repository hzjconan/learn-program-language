## 1. 路径、编码与文件的关闭

`Path("data") / "prompts.txt"` 拼出路径 `data/prompts.txt`。相对路径从 Python 进程的当前工作目录算起，可用 `Path.cwd()` 查看。在调用 `.open()` 时，`"r"` 表示以文本模式读取，`encoding="utf-8"` 指定如何把文件字节解码成字符串。

```python
from pathlib import Path

path = Path("data") / "prompts.txt"

with path.open("r", encoding="utf-8") as file:
    print(repr(file.readline()))  # ①
    print(file.closed)           # ②

print(file.closed)               # ③
```

进入 `with` 后，可以通过 `file` 读取内容。离开代码块时，文件对象会自动关闭，即使代码块因异常退出也是如此。这和 P07 用 `finally` 做清理的用途相同。`with` 负责调用资源的退出逻辑。

假设文件存在，第一行是“你好”，且行末有换行。`readline()` 会保留这个换行，`repr()` 会把它显示为 `\n`。`file.closed` 是布尔值。先预测 ①、②、③ 的输出。

① 输出 `'你好\n'`，② 输出 `False`，③ 输出 `True`。`with` 结束后，变量 `file` 仍指向原文件对象，可以检查 `file.closed`。

## 2. 逐行读取与文件末尾

文件对象可以迭代，每次取一行。配合 `enumerate(file, start=1)` 得到从 1 开始的实际行号。假设内容用 Python 字符串表示是 `"你好\n\n再见"`，中间是空行，末行没有换行。

```python
with path.open("r", encoding="utf-8") as file:
    for line_no, line in enumerate(file, start=1):
        print(line_no, repr(line))  # ① 每行执行一次
    print(repr(file.readline()))   # ②
```

```text
1 '你好\n'
2 '\n'
3 '再见'
''
```

逐行读取保留原有行尾，末行缺少换行也会被读取。空白行 `"\n"` 有一个字符。打开的文件读到末尾时，`readline()` 返回 `""`。

## 3. JSON 与 JSONL

`json.load(file)` 从文件对象读取一个完整的 JSON 值，可以跨行排版。JSONL 用每行一个独立 JSON 值保存多条记录，例如：

```jsonl
{"id": 1, "prompt": "你好"}
{"id": 2, "prompt": "再见"}
```

对整份文件使用 `json.load(file)` 会抛出 `json.JSONDecodeError`，因为第一个对象结束后还有第二个对象。用 `for line in file` 逐行调用 `json.loads(line)` 则依次得到两个 Python 字典。

## 4. 主练习：逐行读取 JSONL

在 `python/jsonl_reader.py` 实现 `load_jsonl(path)`，用 `Path(path).open("r", encoding="utf-8")` 和 `with` 逐行读取。返回 `(records, errors)`，按文件中的顺序收集成功解析的 JSON 值和报错信息。

- 用 `enumerate(file, start=1)` 取得真实文件行号。使用 `line.strip()` 判断空白行，本练习约定跳过空白行，之后的行号按原文件计数。
- 对其余每行调用 `json.loads(line)`。捕获这一行的 `json.JSONDecodeError`，在 `errors` 中加入 `(line_no, exc.msg)` 后继续。`exc.lineno` 是传给 `loads` 的那段字符串中的行号，记录文件行号时使用 `enumerate` 的结果。
- 打开文件失败时，将异常交给调用方。例如路径不存在时，调用方可以收到 `FileNotFoundError`。

用如下输入内容验证。第三行是无效 JSON，第四行末尾没有换行。

```python
sample = '{"id": 1, "prompt": "你好"}\n\n坏数据\n{"id": 2, "prompt": "再见"}'
```

在 `main()` 中可以用 `with TemporaryDirectory() as directory` 建立临时目录，将 `sample` 用 `path.write_text(sample, encoding="utf-8")` 写入该目录下的文件。验证成功记录的 ID 按顺序为 `1`、`2`，只有一项错误，报错行号为 `3`。错误文字由 JSON 解析器提供，断言检查行号即可。

初版用 `str(exc)` 会返回 `(3, 'Expecting value: line 1 column 1 (char 0)')`。元组里的 `3` 是实际文件行号。消息中的 `line 1` 是这次送给 `json.loads` 的单行字符串里的行号。用 `exc.msg` 后得到 `(3, 'Expecting value')`，既保留真实行号，也保留解析失败的原因。

## 5. 用 `tempfile` 创建和清理测试文件

`tempfile` 是 Python 标准库。几种常用接口按需要的资源来选。

| 接口 | 创建的资源 | 默认清理方式 |
|---|---|---|
| `TemporaryFile()` | 直接拿来读写的文件对象 | 关闭文件对象时清理 |
| `NamedTemporaryFile()` | 有可用路径的临时文件，路径可通过 `.name` 取得 | 默认关闭时删除 |
| `TemporaryDirectory()` | 临时目录，可以在其中创建指定名称的文件 | 退出 `with` 时清理目录及其内容 |

本练习的读取函数接收路径，可在临时目录里创建 `prompts.jsonl`。`write_text()` 写完后关闭文件，内容继续保存在磁盘上。目录清理发生在外层 `with` 退出时。

```python
from pathlib import Path
from tempfile import TemporaryDirectory

sample = '{"id": 1, "prompt": "你好"}'

with TemporaryDirectory() as directory:
    path = Path(directory) / "prompts.jsonl"
    path.write_text(sample, encoding="utf-8")
    print(path.exists())  # True
    # 在这里调用 load_jsonl(path)，然后验证结果。

print(path.exists())  # False
```

退出 `with` 时会执行清理，即使代码块抛出了异常。`path` 这个变量仍然可以访问，保存的是已被删除的文件路径。若手动管理 `TemporaryDirectory()`，可以调用它的 `.cleanup()`。若用 `NamedTemporaryFile(delete=False)` 保留文件，则可以事后用 `Path(name).unlink()` 删除。
