## 1. 函数从哪里读取名字

在普通函数中读取名字时，可以用 **LEGB** 记住查找顺序。内层找到同名绑定后，就使用那个绑定。

| 顺序 | 查找位置 | 例子 |
|---|---|---|
| L · Local | 当前函数的局部作用域 | 当前函数的参数 |
| E · Enclosing | 定义它的外层函数，从最近一层开始 | 外层函数的参数或变量 |
| G · Global | 定义当前函数的模块 | 文件顶层的 `model` |
| B · Built-in | Python 内置名字 | `len`、`print` |

这里的外层由函数**写在哪里**决定。调用发生在别的函数里时，调用方的局部变量不会被加入查找路径。

```python
model = "module-model"

def show_model():
    print(model)

def run():
    model = "caller-model"
    show_model()

run()  # module-model
```

`show_model` 定义在模块顶层，所以它从模块找到 `model`。`run` 中的同名局部变量只对 `run` 及定义在它内部的函数可见。

### 预测题

先不运行，预测三行输出，并说出每一行的 `model` 在哪里绑定。

```python
model = "module-model"

def outer():
    model = "outer-model"

    def inner(prompt, temperature=0.7):
        print(model, len(prompt), temperature)  # ①

    inner("hi", temperature=0)
    print(model)  # ②

outer()
print(model)  # ③
```

① 输出 `outer-model 2 0`。`model` 来自外层 `outer`，`prompt` 和显式传入的 `temperature=0` 来自 `inner` 的参数，`len` 来自内置作用域。② 输出 `outer-model`，此时 `model` 是当前函数的局部变量。③ 输出 `module-model`，读取模块顶层的名字。

## 2. 赋值与 `global`、`nonlocal`

函数体里给一个名字赋值时，Python 通常把它视为整个函数的局部名字，除非通过 `global` 或 `nonlocal` 指定别处的绑定。

```python
model = "module-model"

def choose_model():
    print(model)  # ① 抛出 UnboundLocalError
    model = "local-model"
    print(model)  # ②

choose_model()
print(model)  # ③
```

① 在读取尚未赋值的局部 `model` 时失败。Python 对局部名字的判断覆盖整个函数体，即使赋值行在后面。异常未捕获，三处 `print` 都没有输出。

```python
model = "module-model"

def outer():
    model = "outer-model"

    def inner():
        nonlocal model
        model = "updated-model"
        print(model)  # ①

    inner()
    print(model)  # ②

outer()
print(model)  # ③
```

| 声明 | ① | ② | ③ |
|---|---|---|---|
| `nonlocal model` | `updated-model` | `updated-model` | `module-model` |
| `global model` | `updated-model` | `outer-model` | `updated-model` |

`nonlocal` 更新最近一个已经绑定该名字的外层函数中的变量。换成 `global` 后，① 和 ③ 读到同一个模块变量，② 仍读 `outer` 自己的局部变量。

## 3. 返回闭包与独立状态

```python
def make_formatter(prefix):
    def format_text(text):
        return f"{prefix} {text}"
    return format_text

format_info = make_formatter("[INFO]")
print(format_info("训练开始"))  # [INFO] 训练开始
```

`return format_text` 返回函数对象。外层调用已结束，返回的函数仍然可以读取那次调用中的 `prefix`。这种函数和它访问的外层绑定构成闭包。外层工厂的每次调用都创建一组独立的局部绑定。

```python
def make_counter(start):
    count = start

    def increment():
        nonlocal count
        count += 1
        return count

    return increment

a = make_counter(0)
b = make_counter(10)
print(a())  # ① 1
print(a())  # ② 2
print(b())  # ③ 11
print(a())  # ④ 3

alias = a
print(alias())  # ⑤ 4
print(b())      # ⑥ 12
print(a())      # ⑦ 5
```

③ 先把 `b` 的 `count` 从 10 加到 11 再返回。④ 读写的是 `a` 自己的 `count`，此时从 2 加到 3。`alias = a` 让两个名字引用同一个函数对象，调用任一名字都会更新同一个 `count`。

## 4. 循环里创建闭包与延迟绑定

```python
def make_formatters():
    formatters = []
    for prefix in ["[INFO]", "[WARN]", "[ERROR]"]:
        def format_text(text):
            return f"{prefix} {text}"

        formatters.append(format_text)

    return formatters

formatters = make_formatters()
print(formatters[0]("训练开始"))  # ① [ERROR] 训练开始
print(formatters[1]("显存不足"))  # ② [ERROR] 显存不足
print(formatters[2]("训练失败"))  # ③ [ERROR] 训练失败
```

三轮定义了三个函数对象。它们在同一次 `make_formatters` 调用中共享一个 `prefix` 绑定，因为 `for` 不创建新的函数作用域。等到调用这些函数时，`prefix` 已经是最后一轮的 `"[ERROR]"`。

可以复用第 3 节的 `make_formatter`，每轮调用一次工厂，让每个函数拿到自己的绑定。另一种写法是在循环中定义 `def format_text(text, prefix=prefix):`，利用默认值在定义时求值，将当轮字符串绑定为形参默认值。这种写法会多暴露一个可由调用者传入的参数，因此本节主练习使用工厂。

## 5. 主练习

在 `python/prompt_filters.py` 实现 `make_prompt_filter(max_chars)`。返回的函数只接收 `prompt`，判断其长度是否小于等于该上限。再实现 `make_prompt_filters(limits)`，按输入顺序返回一个函数列表，每个上限由一次独立的工厂调用绑定。

```python
filters = make_prompt_filters([3, 5])
short = filters[0]  # 检查长度是否 ≤ 3
long = filters[1]   # 检查长度是否 ≤ 5
short("abcd")      # False
long("abcd")       # True
```

创建函数时传入上限，调用返回的函数时才传入文本。`short, long = make_prompt_filters([3, 5])` 是把列表中的两个函数分别赋给两个名字。

用 `main()` 中的断言验证 `short, long = make_prompt_filters([3, 5])`。`short("hey")` 为真，`short("hello")` 为假，`long("hello")` 为真，`long("hello!")` 为假。上限为 0 时允许空字符串，拒绝非空字符串。

练习中每轮调用一次 `make_prompt_filter(limit)`。函数列表保留 `limits` 的顺序，每个返回的函数读取对应那次调用中的 `max_chars`。`<=` 包含长度恰好等于上限的情况。空上限列表会得到空列表。
