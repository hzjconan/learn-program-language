1. 不做优化器更新参数不变；100 次循环更新 100 次、每次 3 个样本。正确。清梯度不清参数。
2. 验证恶化最初认为训练数据不够多；反馈：泛化变差、通常提示过拟合，数据不足只是可能原因。
3. 用户正确指出格式改善而引用下降不能据 loss 宣告成功。
4. 首次口述：分训练/验证集；更新参数；验证 loss 是否可接受；做 eval 测试；保存参数、推理不更新。教师补充清洗去重、独立测试、更新完整步骤、验证选检查点、具体指标和基线、LoRA/续训状态。
5. 最终回答原文：“loss.backward()用来算梯度，optimizer.step()用来更新参数”。正确。

7. 原文：“model.eval()只是切换到评估模式，期间不会更新参数……需要自己准备一些题目和正确答案，看模型的输出正确率”。具体评测思路正确，但“期间不会更新参数”需纠正：eval 本身不禁止更新，正常评估流程不调用更新步骤。
