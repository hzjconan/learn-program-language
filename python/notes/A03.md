### 教师批改

识别出未解包的问题。需要修正：args 是 tuple，即 (10, 20)；kwargs 是 {"tax": 0.1}，保留调用时实际传入的关键字参数。原样调用将 tuple 绑定到 a、dict 绑定到 b，tax 使用默认值 0；先输出 call，随后在 a + b 处引发 TypeError，最外层 print 不会打印结果。只修正解包但不补返回值时，原函数的计算结果被丢弃，wrapper 正常执行到底返回 None，因此输出 call 和 None。33 对应原函数的数学计算结果，不能据此判断包装函数的返回值。

        print("call")
        return fn(*args, **kwargs)
