## yield 初讲

已讲生成器函数调用时返回生成器对象、尚不执行函数体；生成器是迭代器；next 开始或恢复执行，yield 产出值并暂停，局部状态与执行位置保留；return 或执行到底结束迭代。与 JS function* / yield 类比，但 Python 使用 def 中的 yield、以 StopIteration 表示耗尽。下一题预测带 begin、between、end 标记的生成器执行顺序，尚待回答，未运行。

```text
第一个list(g)会被g走完，所以返回了20，打印出了end。第二个list(g)会碰到StopIteration的错，所以最终结果是个空list
```

### 教师批改

正确：调用 numbers 不执行函数体；第一次 next 已产出 10 并在 yield 10 处暂停；第二次 list 消费耗尽的生成器会得到 []。需修正：恢复时先执行 print("between")；yield 20 只是向 list 提供元素，不会直接打印20；list 还会继续取值，执行 print("end") 后遇到迭代结束，再返回 [20]，由外层 print 打印。因此 print(list(g)) 的这一段输出依次为 between、end、[20]。第二次 list 内部处理 StopIteration，调用者不会收到该异常。要求用户重新写完整输出并解释 yield 20 与 print(20) 的区别；尚未修订、未运行。
