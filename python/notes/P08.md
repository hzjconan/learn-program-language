## 答题与批改

- 关闭文件题答 `你好`、`False`、`True`。关闭状态正确，教师补充 `repr()` 的精确输出是 `'你好\n'`。
- 逐行读取题答 `'你好\n'`、`'\n'`、`'再见\n'`，读完后再调用 `readline()` 会报错。前两行内容正确，需补行号。最后一行缺少换行，读完后文件仍打开，调用 `readline()` 返回空字符串。
- JSONL 题答整份 `json.load` 不能成功，逐行会得到两个 ID 为 1、2 的 JSON 对象。判断正确，解析后具体类型是 Python `dict`。
- 用户询问 `tempfile` 如何创建和清理临时文件。补讲三种常用接口，并示范在临时目录中写入测试数据，退出 `with` 后检查文件已被删除。

## 主练习初审

[jsonl_reader.py](../jsonl_reader.py) 保留 ID 顺序，跳过空白行，记录第三行错误后继续读取末行。教师额外验证了只含空格和制表符的空白行、缺失文件异常和临时文件清理，均通过。

初版使用 `str(exc)`，实际返回 `(3, 'Expecting value: line 1 column 1 (char 0)')`。外层的 `3` 是文件行号，消息里的 `line 1` 是这次交给解析器的字符串内的行号。练习约定用 `exc.msg` 保存错误文字。`main()` 目前打印结果，待补上记录顺序与报错行号的断言。

## 修订与复测

改用 `exc.msg` 后，`main()` 断言成功记录的数量、顺序和首个报错行号，运行通过。教师复测错误列表恰好为 `[(3, 'Expecting value')]`，并检查了空文件、缺失文件异常、末行无换行和临时目录退出后的自动清理，均通过。
