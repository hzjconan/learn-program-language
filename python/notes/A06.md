## Task 与事件循环初讲

协程对象表示尚可执行的协程，create_task 将它包装为 Task 并提交给当前事件循环调度。Task 仍可 await，以取得结果或传播异常；等待已有 Task 不意味着届时才开始它。当前例子使用 Python 3.12 默认任务工厂，未配置 eager_task_factory：创建Task先排队，当前main运行到真正让出控制权的位置，事件循环才运行其他任务。sleep(0) 明确让出；本例为单线程内交错推进，不创建工作线程。
