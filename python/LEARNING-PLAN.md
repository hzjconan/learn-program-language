# Python 与 AI 开发教学计划

确认日期：2026-11-16。面向有 JS/TS、Java、Go 经验的开发者。

目标：系统掌握 Python，独立开发 AI 应用，理解、修改和排查模型训练代码。

## 教学方式与时间

每节围绕一个核心知识点，1～2 小时，包含练习和评审。复杂主题拆分，综合项目按独立任务推进。编号表示学习单元，不表示自然日。

| 环节 | 参考时间 | 内容 |
|---|---:|---|
| 回顾与摸底 | 5～10 分钟 | 回访旧知识，熟练内容快速通过 |
| 分段讲解 | 20～30 分钟 | 机制、最小示例、与已有语言的差异 |
| 理解题 | 10～15 分钟 | 预测输出、读代码找错、解释选择 |
| 主练习 | 20～45 分钟 | 用户实现，按需逐步提示 |
| 评审与复盘 | 10～20 分钟 | 正确性、惯用法、边界、设计理由与修订 |

各环节时间按当节调配，总时长控制在 1～2 小时。推进依据是理解和实践结果，不以讲义读完为准。

测试从早期引入：先给必要骨架，逐步由用户补边界、写测试、暴露错误。预测题先推理再运行。错题在后续换场景复测。

## 本机实验约定

- 必修提供 M1 Pro / 32GB 本机版本，PyTorch 用 CPU/MPS，实际项目用 MLX。
- 系统、CPU、GPU 共享内存，不把 32GB 全部作为模型预算。
- 先做短实验测量耗时和内存；课堂尽量几分钟内反馈，不要求租 GPU。
- 长训练作为课间选做，启动前明确实验范围；不作为课内验收前提。
- 小模型用于完整验证求导、冻结、LoRA、保存恢复等机制。CPU 多进程演示不能替代真实 GPU 通信与性能实验。
- CUDA、多卡和大内存实操单列选修。MLX 与 PyTorch MPS 的支持路径分别验证。
